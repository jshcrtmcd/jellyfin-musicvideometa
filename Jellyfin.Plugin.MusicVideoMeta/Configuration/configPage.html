Music Video Metadata

Reads the artist from the first folder in your Music Videos library and the title from the file name, then matches them to your Music library, audiometa.io, MusicBrainz and TheAudioDB. Run it from Dashboard → Scheduled Tasks → Music Video Metadata, or let it run after each library scan.

What to change

Artist, title, year, album and genre, written with ffmpeg. Streams are copied, not re-encoded. The original file is replaced; no backup is kept. Supports mp4, m4v, mov, mkv and webm.
